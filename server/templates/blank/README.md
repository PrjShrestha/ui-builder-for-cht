# CHT project

Generated by the CHT UI Builder. Edit through the UI; deploy with
`cht-conf` (or the Deploy panel in the builder).

## Layout

- `app_settings/base_settings.json` — contact hierarchy, types, locales.
- `forms/app/` — app forms (XLSForm `.xlsx` + generated `.xml` + `.properties.json`).
- `forms/contact/` — contact forms (XLSForm `.xlsx` + generated `.xml`).
- `tasks.js` + `tasks-extras.js` — task definitions and helpers.
- `contact-summary.templated.js` + `contact-summary-extras.js` — summary
  card content + the `context` object surfaced to forms.

## Deploy

```sh
cht --local compile-app-settings
cht --local convert-app-forms
cht --local upload-app-settings upload-app-forms
```

Or click through the Deploy panel in the UI Builder.
