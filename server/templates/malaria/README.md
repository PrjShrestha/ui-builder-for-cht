# Malaria Surveillance — Starter

A CHW workflow for malaria case detection. Generated by the CHT UI Builder.

## Hierarchy

`district` → `municipality` → `health_facility` → `chw` → `patient`

## What's wired up

- **base_settings.json** — five-level hierarchy + permissions for `chw` and `national_admin` roles.
- **tasks.js** — `malaria.followup` task: fires 3 days after a `malaria_screening` report where `result === 'positive'`. Resolved when a `malaria_followup` is submitted in window (days 2–7).
- **contact-summary.templated.js** — sets `summary.show_malaria_form = true` for patients with no recent resolved follow-up.
- **properties.json** files — `malaria_screening` shown on patient pages when `summary.show_malaria_form`; `malaria_followup` only opens from the task button.
- **translations** — English + Nepali (`messages-en.properties`, `messages-ne.properties`).

## What's NOT generated yet

The two XLSForm spreadsheets (`malaria_screening.xlsx`, `malaria_followup.xlsx`) are **not** in this scaffold yet. To build them via the UI:

1. Open this project in the CHT UI Builder.
2. Forms → `+ App form` → name it `malaria_screening`. Add rows:
   - `select_one yes_no` named `fever` — "Does the patient have fever?"
   - `select_one yes_no` named `chills` — "Chills or rigors?"
   - `select_one rdt_result` named `rdt_result` (positive / negative / invalid) with `relevant = ${fever} = 'yes'`
   - `calculate` named `result` with `calculation = if(${rdt_result}='positive','positive', if(${rdt_result}='negative','negative','unknown'))`
   - Add referral group with `relevant = ${result} = 'positive'`
3. Repeat for `malaria_followup` with `still_symptomatic`, `adherence`, `danger_signs`, `escalate` fields.

After creating, the Tasks panel will already have `malaria.followup` ready — it'll fire as soon as you submit a screening with `result = 'positive'`.

## Deploy

```sh
# From the project root:
cht --local compile-app-settings
cht --local convert-app-forms
cht --local upload-app-settings upload-app-forms
```

…or click through the Deploy panel in the builder.
